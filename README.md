# Covenant

Covenant is a Gate 0 feasibility test for a graph-derived response to changed source-data obligations. It uses a synthetic Northstar Commerce scenario and must produce one allowed dashboard, two models requiring remediation, one proposed stop, one human review, and one unaffected control.

Start with the [Gate 0 commission](docs/commissions/gate-0-smoke-test.md), then follow the reproduction commands in the [Gate 0 report](docs/gates/gate-0-report.md). No Gate 1 work belongs in this repository until the owner issues a new bounded commission.
